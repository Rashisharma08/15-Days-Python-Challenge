# Day 9 - Dictionary, Tuple and Set

## 📌 Topics Covered

* Dictionary
* Tuple
* Set

## 🧠 Concepts

### Dictionary

Stores data in key-value pairs.

### Tuple

Immutable collection (cannot be changed).

### Set

Stores unique values and removes duplicates.

## ✅ Example

```python
student = {
    "name": "Rashi",
    "age": 20,
    "city": "Bhopal"
}

print(student["name"])
```

* Learned data collections in Python
* Understood differences between List, Tuple, and Set
